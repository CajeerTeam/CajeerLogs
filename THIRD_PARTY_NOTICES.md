- Python client dependencies.
- Java/Kotlin plugin dependencies.

## QRCode for JavaScript

The local browser QR encoder (`public/admin/assets/components/qr-encoder.js`) bundles the QRCode implementation by Kazuhiko Arase from qrcode-terminal 0.12.0 `vendor/QRCode` (MIT license; original source headers retained). The qrcode-terminal CLI and terminal renderer are not bundled. Source: https://github.com/gtanner/qrcode-terminal/tree/v0.12.0/vendor/QRCode.
