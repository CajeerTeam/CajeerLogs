## [0.1.0-initial] - 2026-06-15

### Added

- Начальная архитектурная структура CajeerLogs.
- PHP 8.4+ backend skeleton с PHP 8.5 readiness.
- OpenAPI 3.1.1 contract-first API.
- PostgreSQL, MySQL/MariaDB, SQLite и ClickHouse schema skeleton.
- Nginx-first deploy example и Apache optional example.
- Web Installer + CLI Installer skeleton.
- Nuxt Admin UI skeleton.
- PHP Extension SDK, TypeScript API SDK, Python client, Java/Kotlin plugin skeleton.
- GitFlic Wiki source pages.
- Roadmap до 8.0.0.
