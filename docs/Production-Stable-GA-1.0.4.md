# CajeerLogs v1.0.4 — SkiF4er ID Authentication

- Optional server-side OIDC login with explicit stable-subject account bindings, local TOTP, existing local sessions and RBAC.
- Authorization Code + PKCE, issuer/nonce/audience/signature validation, one-use callback and completion, fail-closed provider errors.

- Live provider SDK documentation was unavailable during development. Configure and test a registered confidential client as described in [SkiF4er ID Authentication](SkiF4er-ID-Authentication-1.0.4.md) before enabling the optional integration.
