# CajeerLogs 1.0.4 — Вход через SkiF4er ID

[История версий](../CHANGELOG.md) · [Приёмка 1.1.0](Production-Stable-GA-1.1.0.md)

## Изменения выпуска

OIDC discovery, Authorization Code + PKCE S256, RSA-подпись, одноразовый callback и локальный TOTP. Привязка по проверенному субъекту, без автоматической связи по email или переноса ролей. Миграция 0034; необходим зарегистрированный клиент и реальная проверка.

## Условия допуска

Сохраняются API v1, действующие механизмы резервного копирования и обязательный GA pipeline. Для одного и того же архива должны пройти матрица PHP/PostgreSQL, проверки безопасности, браузера, SDK, совместимости, восстановления, зависимостей и нагрузки. Подписанные архив и итоговый сертификат обязательны. Наличие версии в коде и локальные тесты не подтверждают публикацию или доступность внешнего сервиса.

Подробности настройки, ограничения и сценарии проверки: [Вход через SkiF4er ID](SkiF4er-ID-Authentication-1.0.4.md). Для актуальной промышленной версии следуйте [контрольному списку](Production-checklist.md).
