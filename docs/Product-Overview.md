# CajeerLogs 1.1.0 — обзор продукта

> Единое рабочее пространство для сбора журналов, диагностики ошибок и управления эксплуатацией.

[Главная](../README.md) · [Документация](README.md) · [Изменения](../CHANGELOG.md)

## Для кого предназначен продукт

| Роль | Основной сценарий |
|---|---|
| Разработчик | Найти конкретный сбой по запросу, трассировке или событию, изучить контекст и проверить гипотезу |
| Инженер эксплуатации | Следить за источниками, очередями, ошибками, задержками и доступностью |
| Администратор | Изолировать проекты, выдавать токены, управлять пользователями, сессиями и обновлениями |
| Руководитель команды | Получать сводки по ошибкам и результатам расследований, не предоставляя лишних прав |

## Путь события

1. Приложение передаёт структурированное событие через API или поддерживаемый SDK.
2. Сервис проверяет токен, проект, источник, подпись и ограничения размера/частоты; защита от повторной доставки предотвращает дубли при корректном использовании идемпотентных запросов.
3. Событие сохраняется в PostgreSQL синхронно либо после выполнения асинхронного задания. Принятие задания не равно завершённой обработке: состояние проверяется отдельно.
4. Авторизованный пользователь находит запись в журнале, изучает детали и связанные события. При настроенной аналитике доступны сводные представления.
5. При включённом ИИ и явном согласии можно запросить объяснение ошибок и сохранить результат расследования в личной истории.

## Основные рабочие области

| Область | Возможности |
|---|---|
| Журналы | Временной интервал, источник, уровень, текстовые фильтры, JSON, корреляция |
| Аналитика | Показатели ошибок и источников, агрегаты, репликация в ClickHouse при настройке |
| Доставка | Пакеты, очередь, повторные попытки, обработка неуспешных задач, ограничение нагрузки |
| Управление | Проекты, источники, пользователи, токены, аудит, политики хранения |
| Безопасность | RBAC, CSRF, HMAC, TOTP, защищённые сессии, управление отзывом доступа |
| Эксплуатация | Диагностика, метрики, резервное копирование, восстановление, выпуск и обновление |

## Возможности версии 1.1.0

- **ChatGPT:** контекстные ответы по доступным логам; расследование по Event ID, Trace ID, Request ID; группировка до 200 ошибок; история результатов только по явному выбору пользователя.
- **SkiF4er ID:** дополнительный OIDC-вход в уже существующий локальный аккаунт; привязка по стабильному идентификатору, проверка локального фактора и отзыв внешних сессий.
- **GitHub:** обнаружение опубликованных версий, журнал изменений, проверка полного архива и сертификата стабильного выпуска; плановые проверки, уведомления и ограниченная безопасная установка.

## Границы продукта

CajeerLogs не выполняет команды по совету ИИ и не устанавливает обновления из браузера с системными полномочиями. ИИ не гарантирует точность причины инцидента; выборка ограничена. Маскирование не является полноценной системой предотвращения утечек. Автоматическое обновление не поддерживает Docker, многосерверное размещение и разделённые роли БД: используйте отдельный операторский процесс. Внешний вход не даёт прав по ролям провайдера и не выполняет глобальный выход из SkiF4er ID. Наличие кода не подтверждает доступность внешнего API, промышленную сертификацию либо конкретные SLA.
