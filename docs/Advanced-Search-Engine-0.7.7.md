# Advanced Search Engine — 0.7.7

Рабочий API v1 поверх PostgreSQL 17+ (без обязательного OpenSearch). Токен или сессия с `logs:read` обязаны иметь доступ к `project_id`, source-scoped токены ограничены своим источником.

## Быстрые фасеты

`GET /api/v1/logs/facets?project_id=UUID&from=2026-11-12T00:00:00Z&to=2026-11-13T00:00:00Z` с `Authorization: Bearer ...`. Принимаются те же фильтры, что и Explorer (кроме `limit`, `cursor`, `consistency`, `interval`). Диапазон обязателен, максимум 7 суток.

Ответ: `total`, массивы `levels`, `sources`, `services`, `hosts` с точными счётчиками `count`, `truncated` и диапазон UTC. Каждый массив содержит не более 20 самых частых значений; `sources[].value` — UUID зарегистрированного источника, `label` — slug. Фасеты вычисляются по всей выборке в одной ограниченной read-only транзакции, а не по первой странице. Контроль statement timeout и rate limiting остаётся действующим.

## Корреляция

`GET /api/v1/logs?project_id=UUID&related_event=EVENT_UUID&relation=either&from=...&to=...` (с URL-encoding значений). `relation` выбирает `trace`, `request` или `either` (по умолчанию). Идентификаторы берутся из исходного события, принадлежащего авторизованному проекту; для source-scoped доступа исходное событие также обязано принадлежать разрешённому источнику. Отсутствующий или чужой UUID даёт пустую выборку, без раскрытия принадлежности. Сравнение идентификаторов точное, непустое, в пределах 7 суток. Курсоры подписаны и привязаны к фильтрам, как и прежде.

В Inspector на вкладке «Связанные события» выберите «Trace или Request». Объединённый режим использует 7-дневное окно вокруг события. Explorer позволяет фильтровать результаты по точным фасетам без повторной загрузки всей выборки.

## Установка и эксплуатация

1. Остановить запись и сделать проверенную резервную копию. Применить дельту поверх 0.7.6.
2. `php bin/cajeer migrate` и `php bin/cajeer migrate:verify`. Индексы создаются транзакционно; для больших таблиц предусмотрите окно обслуживания.
3. `php tests/advanced_search.php`; на изолированной PostgreSQL 17+ установите `CAJEER_TEST_DATABASE=1` и выполните `php tests/advanced_search_database.php`.
4. Проверить авторизованные HTTP-запросы, EXPLAIN (ANALYZE, BUFFERS) на собственной базе и фактический p95/p99. Индексы улучшают возможность выбора плана, но сами по себе не гарантируют SLO.

Постраничная навигация, экспорт, отчёты и PostgreSQL source-of-truth не изменяют семантику. Полная production-сертификация требует прогонов на реальном PostgreSQL и целевой нагрузке.
