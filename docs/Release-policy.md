# Политика выпусков, совместимости и поддержки

## Что считается стабильным выпуском

Стабильный выпуск (GA) — опубликованный через `publish-ga` релиз с проверяемой криптографической аттестацией полного архива и итогового успешного отчёта. Тег, номер версии, исходный ZIP, локальные тесты или канал `stable` сами по себе не подтверждают GA. Предварительные выпуски предназначены для испытаний и не допускаются к автоматической установке.

## Совместимость

| Область | Политика |
|---|---|
| Версии | SemVer; исправления безопасности и совместимости выпускаются в рамках поддерживаемой ветки |
| API | `/api/v1`: сохранение существующих маршрутов, семантики доступа, кодов ошибок и обязательных полей; допустимы добавления |
| Среда | PHP 8.4/8.5 и PostgreSQL 17/18 — матрица проверки; ClickHouse 25.8 — дополнительная аналитика |
| SDK | PHP, Python, TypeScript, Kotlin; совместимость протокола проверяется в CI |
| БД | Для 1.1.0 сохраняются 36 исторических миграций; ранее применённые SQL-файлы не переписываются |
| Интерфейс | Браузерные ресурсы должны соответствовать версии ядра; смешивание версий запрещено |

## Поддержка

Последний сертифицированный выпуск ветки 1.0.x получает критические и значимые исправления безопасности и совместимости до истечения шести месяцев после публичного GA 1.1.0, но не менее 12 месяцев после GA 1.0.0. Обе границы должны быть достигнуты. Раннее прекращение поддержки требует уведомления за 90 дней и пути миграции. Более ранние исправления 1.0.x заменяются новейшими, предварительные выпуски 0.x не имеют гарантии дальнейшего обслуживания. Это политика сопровождения, а не договорное SLA. Не отсчитывайте срок от предварительного релиза.

## Доказательства выпуска

Обязательны проверки PHP/PostgreSQL, ClickHouse, браузера, SDK, TLS и безопасности, резервного восстановления и измеряемых RPO/RTO, обновления и отката, длительной нагрузки, зависимостей и воспроизводимости. Все результаты привязаны к SHA-256 одного архива. `scripts/ga_release.py` проверяет аттестации GitHub OIDC/Sigstore, точный тег, исходный коммит и доверенный workflow. Публикация запрещена при неполных или неуспешных проверках. Опубликованный GA-тег и его артефакты не заменяются.
