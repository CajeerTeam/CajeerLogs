# Search

Рабочий PostgreSQL Full-Text Search, составные фильтры и JSONB в 0.2.8. См. [Log Search](Log-Search.md). Внешние поисковые серверы не требуются; Meilisearch / OpenSearch — будущие optional adapters.

В 0.2.9 HTTP-пагинация использует подписанные курсоры v2. См. [Pagination & Log Explorer](Pagination-Log-Explorer.md).
