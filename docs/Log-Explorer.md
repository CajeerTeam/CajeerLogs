# Log Explorer & Table — 0.3.4

Откройте «Логи», выберите проект, задайте фильтры и нажмите «Найти». Таблица читает реальные события через `/api/v1/logs`; сортировка фиксирована: occurred_at DESC, UUID DESC. Фильтры и запросы не сохраняются в браузерных хранилищах.

## Таблица

«Настроить таблицу»: 12 колонок, видимость, порядок (стрелки вверх/вниз), ширина 90–800 px, плотность, перенос текста, UTC/локальное время. Настройки отображения хранятся в памяти текущего сеанса и сбрасываются при выходе. UTC сохраняет микросекунды сервера; локальное представление округлено до миллисекунд. Сообщения в таблице ограничены 2000 символами, полное содержимое доступно в деталях; копирование использует значение ответа API. Подсветка — буквальное совпадение поисковой строки, не PostgreSQL FTS-rank. Все значения отображаются как текст, без HTML-инъекций.

Таблица имеет закреплённую шапку и независимую прокрутку. Tab переносит фокус, стрелки вверх/вниз на «Подробнее» перемещают фокус между строками; Enter открывает событие. В деталях можно открыть соседнее событие текущей страницы. Курсор, горизонтальная и вертикальная позиция и выбранная строка восстанавливаются при возврате к разделу с теми же фильтрами.

## Пагинация и обновление

Размеры страницы 25/50/100 — верхняя граница; сервер также ограничивает байты ответа. «Назад»/«Далее» используют подписанные prev_cursor/next_cursor, не OFFSET. Номер страницы — локальная позиция навигации, не точный номер в базе. «Обновить страницу» повторяет page_cursor; «К последним событиям» и «Начать заново» создают новый поиск (в snapshot — новый watermark). Истёкший курсор можно заменить новым поиском; ошибка сети не уничтожает ранее загруженную страницу. 401/403 очищают результаты.

Live: новые события могут менять состав страниц. «Проверить новые события» сравнивает digest первой страницы с ранее загруженной первой страницей; опциональная проверка каждые 60 секунд только в видимой вкладке, прекращается при уходе со страницы/401/403/429. Изменение digest означает изменение состава/данных первой страницы, не точное число новых событий. Не перемещает таблицу: переход к последним — явный. Snapshot ограничен received_at watermark, но retention может удалить события; автоматическая проверка выключена.

## Экспорт и безопасность

CSV/JSON экспортируют полную текущую серверную страницу (не только видимые колонки) с page_cursor и If-Match page_digest; X-Page-Digest проверяется до сохранения. При расхождении требуется обновить страницу. Все запросы используют существующий API-клиент, cookie-сессию, RBAC и project scope. Смена раздела/проекта отменяет запросы; параметры поиска и курсоры не записываются в URL, localStorage или sessionStorage.

Обновление 0.3.3 → 0.3.4 не меняет миграции 0001–0015 или wire-контракты. Node.js нужен для проверки JS/CSS, не для эксплуатации. Public Preview до полного CI.
