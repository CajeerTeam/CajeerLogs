# Event Details & JSON Viewer — 0.3.6

Откройте «Подробнее» в Log Explorer или на Dashboard. Инспектор получает событие через `GET /api/v1/logs/{event}?project_id=…`, используя текущую cookie-сессию. Вкладки «Обзор», «Поля», «JSON context», «Raw JSON» и «Связанные события» работают с фактическим ответом API. Обзор оставляет доступными сообщение, метаданные и контекст. Кнопки соседних событий сохраняют навигацию по исходной странице.

## JSON

- Ветви объектов/массивов раскрываются по требованию, по 100 дочерних полей. Максимум 3000 построенных узлов в одном дереве; повторное открытие вкладки сбрасывает этот бюджет. Строки и подписи сокращаются только визуально, копирование и скачивание сохраняют полные значения.
- Поиск без учёта регистра по декодированным ключам/строкам и остальным скалярам: до 20 000 посещённых узлов, до 100 совпадений. Ограничения явно показаны.
- Копирование ключа, значения, JSON Pointer (RFC 6901). Путь относится к корню `context`, а не ко всему событию.
- Фильтрация по выбранному полю в Explorer: существование объекта/массива либо сравнение скаляра. Используется тот же `context_path`/`context_equals`, что и конструктор 0.3.5. При отсутствии подходящего диапазона выбираются 24 часа вокруг timestamp события; другие фильтры сохраняются. Ограничения API (8 сегментов, 31 день, размер параметров) остаются в силе.
- Raw JSON: исходный объект `data` ответа API, переключение форматирования (до 256 КиБ символов результата), копирование, скачивание `event-<uuid>.json`. Числовые литералы копируются из текста ответа, не через JavaScript Number. Серверная политика StoredLogJson (исторические числа могут быть представлены строками) остаётся неизменной; это не доступ к необработанному ingest payload. В частности, сравнение строки, полученной от сервера вместо исторического числа, может не совпасть с исходным JSONB-типом.

## Связанные события

Выберите Trace ID или Request ID. Поиск выполняется по точному идентификатору во всём текущем проекте, независимо от фильтров исходной страницы. Используется `GET /api/v1/logs` с `consistency=snapshot`, `limit=25` и подписанными курсорами. Текущее событие отмечено; другое можно открыть, не закрывая диалог. «Открыть в Log Explorer» начинает новую выборку по выбранному ID. При отсутствии идентификаторов отображается пустое состояние, запрос не отправляется.

## Безопасность и обновление

API v1, RBAC/project scope, redaction, SQL-бюджет и серверный detail budget сохраняются. Нет новых endpoints, схемы или зависимостей. Запросы отменяются при смене события/вкладки/маршрута или завершении сессии; поздние ответы не перезаписывают инспектор. Данные не сохраняются в URL или browser storage. 404 может означать retention, 413 — превышение бюджета ответа. 401/403 закрывают доступ к данным. Для обновления 0.3.5 → 0.3.6 миграций нет; предыдущие миграции 0001–0016 неизменны.

Проверки: `npm --prefix admin run build`, `php bin/cajeer openapi:lint`, `python tests/admin_browser.py`, `python tests/admin_browser_database.py` (требует отдельную PostgreSQL БД). Offline fixture browser: `CAJEER_BROWSER_OFFLINE=1 python tests/admin_browser.py`.
